远程命令参考

setup 完成后，以下命令可在远程主机上使用。代理默认关闭，按需开启，退出 shell 自动失效。
命令 作用域 说明
srg-on session 开启代理，当前 shell 的 curl / pip / git / npm 等走代理
srg-off session 关闭代理，恢复直连。关闭终端也自动失效
srg-shell session 开一个自带代理的子 shell，exit 即恢复
srg-proxy <cmd> process 单条命令透明代理 (mgraftcp)，适用于不认环境变量的程序
srg-status info 查看当前代理状态、隧道连通性、环境变量
Language Server always LS wrapper 始终走代理，不受 srg-on/off 影响
💡 典型使用场景
srg-on && pip install torch 通过代理加速安装 Python 包
srg-proxy curl api.openai.com 单次通过代理访问外网 API
srg-shell → git clone ... → exit 子 shell 批量操作，退出自动清理
